# 🖼️ Лабораторная работа №2

Многостраничный сайт с использованием технологий HTML и CSS.

Основная разметка сайта и стили были использованы из работы на производственной практике. Ссылка на репозиторий производственной практики: [GitHub](https://github.com/Sie1s/6303zimin_practice)

## Требования к реализации

### 1.	Количество страниц – от 3 до 5. ✅

Созданы макеты 3 страниц сайта:

- [index.html](./lab2/index.html) — главная страница
- [blog.html](./lab2/blog.html) — блог
- [hotels.html](./lab2/hotels.html) — размещение

### 2.	Требования к HTML: ✅

#### 2.1.	Использование блочных и строчных элементов. ✅

В работе присутствуют все требуемые типы структур

| Тип структуры | Примеры из работы |
|---|---|
| Блочные | `header`, `main`, `section`, `div`, `ul`, `li`, `p`, `h1`-`h3`, `form`, `fieldset`, `footer` |
| Строчные | `a`, `span`, `img`, `button` |

#### 2.2.	Ссылки – от 1 шт. ✅

В работе присутствует множество ссылок, включая навигацию по якорям, `tel:` и `mailto:`

#### 2.3.	Картинки – от 1 шт.

В работе представлено множество изображений, как растровых (например, фотографии мест отдыха), так и векторных (например, изображение логотипов).

Все используемые в работе изображения хранятся в папке [img](./lab2/img)

#### 2.4.	Таблица – от 1 шт. ✅

На странице [hotels.html](./lab2/hotels.html) размещена таблица `.price-table` с тремя столбцами.

### 3.	Требование к CSS: ✅

#### 3.1.	Отдельный подключаемый файл. ✅

В работе в секции `head` подключены два файла стилей:

| Имя файла | Предназначение |
|---|---|
| [normalize.css](./lab2/css/normalize.css) | Позволяет сделать отображение HTML-элементов в разных браузерах более согласованным |
| [style.css](./lab2/css/style.css) | Основной файл стилей. В нём описана основная реализация стилей разметки  |

#### 3.2.	Обязательное использование как минимум 3 видов селекторов. ✅

В работе 4 вида селекторов

| Вид селектора | Примеры |
|---|---|
| Селектор тегов | `body`, `a`, `img` |
| Селектор классов | `.header`, `.btn`, `.main-header` |
| Селектор псевдоклассов| `:first-child`, `:last-child`, `:not`, `:nth-child` |
| Комбинированные селекторы| `.info .main-text` |

#### 3.3.	Использование цвета. ✅

В работе использовано множество различных цветов. Основные цвета страницы:

| Цвет | HEX | Где используется |
|------|-----|------------------|
| Светло-серый фон | `#F1F1F1` | фон `body` |
| Белый | `#FFFFFF` | карточки, блоки, шапка |
| Тёмный | `#333333` | заголовки, фон футера |
| Акцентный оранжево-золотой | `#CC9933` (`#c93`) | кнопки, ссылки, иконки |
| Серый | `#666666` | навигация, телефон в шапке |
| Приглушённый серый | `#999999` | город, подписи, второстепенный текст |
| Светло-серый | `#E9E9E9` | фон блока бронирования, разделители |
| Чёрный | `#000000` | текст в блоке бронирования |

#### 3.4.	Использование различных видов выравнивания в таблице (по левому/правому краю и по центру). ✅

Для столбцов на странице [hotels.html](./lab2/hotels.html) задано разное выравнивание:

| Столбец | Выравнивание |
|---|---|
| Отель | `text-align: left` |
| Город | `text-align: center` |
| Цена за ночь | `text-align: right` |

### 4.	Запрещено использовать JS, Bootstrap и любые другие библиотеки и фреймворки, всё реализовать самостоятельно.✅

В работе помимо основных файлов разметки [index.html](./lab2/index.html) и файла стилей [style.css](./lab2/css/style.css) также использованы файлы шрифтов (находятся в папке [fonts](./lab2/fonts/)) и файл нормализации стилей ([normalize.css](./lab2/css/normalize.css)). Данные файлы не вносят критические изменения, могут быть удалены по требованию.
