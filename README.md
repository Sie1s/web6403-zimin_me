# 🎨 Лабораторная работа №4

**Цель:** изучение современного CSS и основ ООП на JavaScript. Проект расположен в папке [lab4](./lab4/).

## Требования к реализации

### 1. Вёрстка с помощью Flexbox – 1 страница ✅
Страница [blog.html](./lab4/blog.html) свёрстана с использованием Flexbox. 
Для сетки карточек статей используется `display: flex`, `flex-wrap: wrap` и `justify-content: space-between` для равномерного распределения элементов.

### 2. Вёрстка с помощью Grid – 1 страница ✅
Страница [hotels.html](./lab4/hotels.html) свёрстана с использованием CSS Grid. 
Сетка карточек отелей реализована через `grid-template-columns: repeat(3, 1fr)` и `gap: 24px`, что обеспечивает идеальную адаптивность и равные отступы.

### 3. Задание всех цветов только с помощью переменных в CSS ✅
В файле [style.css](./lab4/css/style.css) в псевдоклассе `:root` заданы все используемые цвета:
- Основные: `--color-accent`, `--color-dark`, `--color-bg`, `--color-white`.
- Для анимации: `--color-mask-opaque`, `--color-mask-transparent`.

### 4. Реализация анимации с помощью CSS – 1 шт. ✅
На главной странице [index.html](./lab4/index.html) реализована бесконечная анимация «Виртуальный тур» с эффектом 360-градусной панорамы.
- **Реализация:** используются две одинаковые картинки в треке, которые бесконечно сдвигаются через `@keyframes pan-scroll`.
- **Эффекты:** плавное затухание по краям блока реализовано через `mask-image`.

### 5. Реализация страницы с формой ✅
На странице [index.html](./lab4/index.html) в секции «Хочу тур» реализована форма, содержащая 3 различных типа полей:
1. `select` (выбор города и страны).
2. `date` (выбор даты прибытия).
3. `number` (количество ночей и туристов).

Также реализована кнопка отправки данных «Найти». Дополнительно через JS настроена HTML-валидация: с помощью атрибута `min` пользователь не может выбрать дату в прошлом.

### 6. Создание класса и обработка данных на JS ✅
В файле [js/form.js](./lab4/js/form.js) реализован класс `TourRequest`:
- **Конструктор** принимает и сохраняет данные из формы.
- **Метод `printToConsole()`** форматированно выводит данные в консоль.
- При нажатии на кнопку «Найти» JS перехватывает `submit` (через `event.preventDefault()`), собирает данные через `FormData`, создает экземпляр класса и вызывает метод вывода в консоль.

### 7. Бонус: Использование методологии БЭМ ✅
Разметка и стили полностью переведены на методологию БЭМ. 
Используются блоки, элементы и модификаторы (например: `booking__fieldset`, `placement__list_grid`, `promo__card` и т.д.). Вспомогательные классы (например, `flex`) оставлены для базовой утилитарной стилизации.
